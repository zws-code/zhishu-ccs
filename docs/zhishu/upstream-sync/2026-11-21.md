## 数据、安全与回退

schema 25 → 26 添加默认关闭的 WorkBuddy MCP/Skills 标志并幂等补齐历史分支缺列；26 → 27 添加仓库 `host`（默认 github.com）与技能 `repo_host`。账号目录/keyring 不迁移，平台 Key 生命周期仍归服务端。

代码回退：`git revert -m 1 <本次 merge 提交>`，第一父为 `56cba5065`。未来若真实运行已迁移 schema 27，旧程序会拒绝高版本库，须恢复升级前的独立数据库备份；不能仅回退代码或降低 user_version。工具配置、恢复备份和 keyring 分别评估，不整目录覆盖。

本轮仅在临时 CC_SWITCH_TEST_HOME 和既有夹具执行测试，未启动真实应用、改写真实工具配置/数据库、读取或清理真实 keyring；没有修改智能体 HOME/CODEX_HOME 来隔离。模拟 HTTP 使用回环端口，no_proxy/NO_PROXY 仅豁免回环。
