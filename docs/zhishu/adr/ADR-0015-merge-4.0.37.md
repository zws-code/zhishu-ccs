# ADR-0015：合并上游 v4.0.37

- 日期：2026-11-21
- 状态：已选定并实施，验证结果见同步报告；不构成发布或实机验收批准。
- 范围：L3 上游核心同步；产品保持 0.0.11。

## 背景、目标与方案

从产品 `56cba5065`（已合入 v4.0.29）三方合并官方 v4.0.37 / `a8ca5e83a28c806463c03d239f7d667260a4ec4c`，tag 对象 `903a1622662aab2c8f55302c6427594ca223d0df`。237 个上游提交、792 个文件涉及 WorkBuddy、隐私过滤、应用能力表、代理协议、Skills 多仓库主机、后台更新、数据库及 DAO 重构。

选择在 `codex/sync-upstream-4.0.37` 保留祖先关系的 merge，继续复用上游 Provider、DAO、IPC、原子写入、模式、MCP/Skills 和代理。选择性 cherry-pick 会遗漏关联修复并损失 tag 祖先关系；用上游树覆盖产品会丢失平台、身份及共存边界，因此不采用。

核心内部签名、锁和分发无法只通过新增 UI 包装适配：平台调用按新的 `AppType` DAO 契约调整；既有审计包装和 WorkBuddy 局部恢复仍在 Provider 写入路径中；迁移继续在原 DAO savepoint 内执行。

## 本次明确授权的规范例外

用户在本轮确认：**“允许采纳官方删除，保留智枢所需兼容（推荐）”**。因此本次允许采纳 v4.0.30–v4.0.37 官方删除未使用 API、组件、类型和依赖的重构，覆盖 AGENTS.md 第 8 节的一般禁止删除要求。该授权只针对此次官方同步，不是未来任意清理的长期许可。智枢仍依赖的严格 Gemini 解析、目录覆盖和平台适配兼容入口保留；没有恢复密码登录或旧 Key 生命周期。

## 数据、安全和平台边界

- schema 25 → 26 增加 WorkBuddy MCP/Skills 标志，并幂等补齐历史分支缺列；26 → 27 增加 `skill_repos.host`（默认 github.com）与 `skills.repo_host`。保留智枢旧 v22/v23 的 OMP/端口协调和回滚测试。
- 平台 OAuth2、keyring、七天闲置、账号隔离目录、两阶段同步及 13 应用平台白名单不扩大；新增 WorkBuddy 授权中心能力属于上游工具账号链路。
- WorkBuddy 使用上游官方账号、MCP/Skills、提示词、会话与用量；普通新卡复用上游模型写入与逐模型覆盖，平台卡/旧未标记模型沿既有适配器保留配置形状、设置覆盖和局部回滚，桥接上游归属查询。写入模型使用 `zhishuCcsProviderId`，不接管原版 `ccSwitchProviderId`；官方卡不写 models.json。进入既有 Adapter 前释放新增外层同一应用锁，避免重复加锁。
- Codex 继续用智枢模型目录、路由表、Stack 前缀和代理占位符。代理代码抽取到子模块后，当前/旧占位符的出口拦截随迁移保留。
- 保持智枢 0.0.11、identifier、深链、数据目录、COS 更新源及发布工作流；后台更新复用 Tauri 验签和用户确认安装，不发布上游版本。
- 新德语沿用上游翻译，尚无德语的智枢及历史兼容字符串暂用英语；自动键覆盖不等于翻译或实机验收。

## 验证、回退与复审

执行前端类型、格式、单测与构建，Rust fmt、Clippy 和隔离目录下的单元/集成测试，另跑本机发布脚本回归。逐项结果、失败与修复见 [2026-11-21 同步报告](../upstream-sync/2026-11-21.md)。不启动真实应用、不写真实工具配置或 keyring。

代码回退：`git revert -m 1 <本次 merge 提交>`，第一父为 `56cba5065`；不重写已发布历史或移动 tag。若未来真实运行迁移了 schema 27，旧程序会拒绝高版本库，必须恢复升级前独立数据库备份，不能只回退代码或手改 user_version。工具配置、账号凭据和备份分别评估，不做整目录覆盖恢复。

发布前复审 Windows/Linux 编译、真实 CLI/WorkBuddy 调用、OAuth/keyring、跨版本安装更新、原版共存及语言显示；本机自动检查不能代替这些验收。
