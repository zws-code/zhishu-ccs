# ADR-0004：平台仅使用客户端专用 API

> 适用范围：首次实施时使用单文件 v2；当前账号目录及旧 v2 迁移由 ADR-0005 延伸，v1 仍不接管。

- 日期 / 复审：2026-10-31 / 下次客户端协议或快照变更时
- 状态：依据用户明确要求实施；用户要求删除旧平台 API 和相关逻辑，无旧接口兼容回退。
- 依据：[接入契约](../api/client-api.md)、ZCCS-DEV-001。

## 场景与验收

客户端登录、恢复会话、基础同步和额度展示统一走 `/api/zhishu/v1/client`。Key 是服务端按账户/分组管理的多客户端共享凭证，客户端不再通过后台路由自行查找、创建、替换或删除。验收包括专用路由独占、失败不回退、账户隔离、只读额度不污染凭证/模型快照、两阶段同步无越界，以及未知模型能力不被写成平台已声明值。

## 候选方案与选择

1. 只改 URL、继续拼接旧分组/Key/订阅请求：不能满足聚合响应和共享 Key 生命周期，否决。
2. 增加新接口、保留失败回退：违反本次用户要求和服务端契约，否决。
3. 在已有自有模块替换网络链路，保留 IPC 名称和受控 Provider 服务：采用。

删除范围仅为自有平台旧实现及对应旧行为测试，不删除上游通用 Provider、OAuth、模型检测、DAO 或配置引擎。已有 AGENTS 与标准关于客户端建 Key、前缀授权及旧快照兼容的描述，本任务以新接入契约和用户本次明确指令替代，记录为业务规则更新而非静默例外。

## 模块与侵入等级

- L0：`src-tauri/src/zhishu/services/client_api.rs` 新 DTO；自有认证、目录、适配器、快照、前端 API/query/组件与回归。
- L1：`src-tauri/src/lib.rs` 增加一个 `platform_get_client_config` 注册；五份共享翻译文件增加额度文案。
- L2：`src-tauri/src/provider.rs` 与 `src/types.ts` 增加可选 `platformManaged.connectionBaseUrl`。已有 Provider 序列化类型必须认识该字段，外部包装无法保证元数据随 Provider 的 DAO 读写往返；不修改 DAO/schema 或通用写入机制。
- 复用 ProviderService Adapter、应用锁、路径解析、私密原子写入、原有配置增量发布/恢复、会话 keyring 和 TanStack Query 账户隔离。

## 数据、安全与兼容

- 本地 `platform-catalog.json` 升为版本 2；先检查版本，再解析新 DTO。旧版本返回无目录并要求重新同步，不接管/迁移旧 Key，也不自动删除旧文件。
- 保存 `synced_at` 的服务端时间、额度、全部订阅、凭证元信息和连接目录。普通摘要没有 Key；显式单 Key 读取继续校验当前账户和快照归属。Unix 使用原有 0600 私密原子写入。
- `keyAvailable` 只表示明文存在，额度由独立 `quota` 表示。目录失败保留本地 Provider，不借用其他模型。成功空集合可协调本账户已撤销授权的 Provider，当前项无安全备用仍保留。
- 额度 IPC 名称不变，返回形状改为 `{ baseUrl, userId, syncedAt, balance, groups }`；嵌套服务端对象保持 snake_case，前端和测试同步升级。Key/连接/模型不属于只读额度 DTO。
- 网关地址与登录 origin 分离；JWT 不发送到网关或网页 URL。注册/找回密码开关和网页地址来自 config，拒绝非 HTTP(S) 链接。密码登录仍拒绝尚不支持的人机验证。
- 缺少 refresh token 时清除上一会话持久化条目，返回无法自动续期警告；401 继续轮换并先保存新 token。退出只撤销当前 refresh 会话，不删共享 Key。
- 新网关元数据只记录地址，不含凭证。更新仍匹配旧生成值的 URL；自定义地址、未知配置及 TOML 注释保留。
- 工具必须填具体能力/窗口时，在适配器明确使用本地默认策略；平台摘要、快照和 `AgentModel` 仍保留未知值。端点目录不扩展模型授权范围。

## 测试与回退

2026-10-31 后续清理：删除无生产入口的 Provider/目录凭证清理、SessionStore 身份查询，以及仅为该旧流程保留的测试；目录不再携带 `credentialsCleared`/`credentials_cleared`，不再提供旧清理错误码和占位 Key。版本 2 的正常快照继续可读，旧版本仍拒绝接管；损坏或空凭证目录拒绝读取，保留原文件。`keyAvailable` 与服务端额度语义保持不变，退出保留本机 Key、账户隔离和配置不变的回归继续覆盖。同时移除旧模型目录的 `api_format`、`mode`、嵌套 limit 和 camelCase 元数据回退及旧形状夹具，模型映射只读取新协议白名单字段。此项属于用户明确要求清理旧二开逻辑的 L0 变更，共享字典仅删除自有旧文案（L1）。

执行结果见 [VALIDATION](../history/validation.md)。使用本机模拟 HTTP、临时目录、内存数据库和模拟凭据库；不以测试通过宣称真实服务端、多设备、系统 keyring 或 CLI 已验收。真实平台端到端、macOS/Windows/Linux 凭据库和工具运行待实测。

回退代码可恢复本次补丁前版本，但旧版本只支持旧 API，不能作为新接口故障的自动回退。客户端故障应修复或暂停基础同步；原生配置和 Provider 数据保持可用。版本 2 快照不向版本 1 降级；若人工回退到旧客户端，须保留原快照备份并重新同步，不能重新发明旧 Key 管理逻辑。未执行发布或远程推送。
