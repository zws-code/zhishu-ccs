# ADR-0005：按账号保存基础数据与清理退出

- 日期：2026-10-31
- 状态：按用户明确授权实施；多账号同时保持登录暂缓
- 范围：L0 自有业务、存储及测试；L1 IPC 注册与共享翻译
- 复审：真实 keyring 与跨平台验收时

## 场景与验收

用户需要保留普通退出，同时可以显式「退出并清除此账号本机数据」。不同账号先后登录时，平台基础数据不能互相覆盖；页面只展示当前已验证账号，明确显示邮箱、平台地址和用户 ID。

验收要求：普通退出保留目录、供应商和原生配置；清理退出只作用于已验证的平台地址 + 用户 ID；安全删除失败或无备用项必须保留并报告；各步骤失败不阻止后续步骤及退出。不能撤销服务端共享模型 Key，不能删除其他账号、自建供应商、授权中心账号、配置修改记录和恢复备份。

## 选择与备选

选择每账号一个目录文件，继续使用版本 2 内容契约。相对当前设备目录为 `platform-catalogs/<sha256(JSON([baseUrl,userId]))>.json`。路径由后端已验证身份生成，内容仍核对身份；私密原子写入、Unix 0600，以及正式/开发设备路径规则保持不变。

未选一个多账号 JSON：更新容易扩大损坏及覆盖范围。未选在退出时默认删数据：普通退出必须保持已配置工具可用。未选统一清空数据库或工具目录：无法保护其他账号、手工配置、原生凭据及恢复材料。

## 旧快照处理

- 优先读取账号文件。内容身份不符或凭证损坏时拒绝，不回退到旧文件。
- 账号文件不存在时，仅迁移归属匹配且内容有效的旧 `platform-catalog.json` v2：先私密原子写入账号文件，成功后移除旧文件。写入失败保留旧文件。
- 新同步保存账号文件后，移除归属明确且匹配的旧文件；损坏、无法判断归属的旧文件保留，不阻塞新的有效快照保存。
- v1 不作为模型目录读取、不迁移字段或接管旧凭证；显式清理允许删除归属明确且匹配的旧文件（包括 v1）。未知归属旧文件保留并报告清理未完成。
- 显式清理先尝试删除匹配的旧文件，再删除账号文件；两项均尝试。成功后不会从旧文件重新迁移。删除失败不得宣称全部清理完成。

## 清理退出流程

新增 `platform_logout_and_clear_account({ baseUrl, userId })`。操作锁覆盖验证、清理及退出；当前内存会话中经服务端验证的邮箱仅用于报告身份，前端不能提供任意邮箱。恢复尚未完成身份验证时不能发起清理。

1. 在 APPLY_LOCK 内验证请求身份，不匹配则拒绝，无删除和退出副作用。
2. 阻塞线程中复用现有全应用删除函数、ProviderService Adapter、应用锁、原生写入/恢复和 `platform_delete` 审计。遍历全部支持应用，含隐藏应用；当前项无安全备用项时保留。
3. 删除该账号的本机目录文件。与供应商删除分别记录结果。
4. 保留登录账号记录、服务器地址和已记住密码，不访问登录历史或密码凭据库；用户可用登录页原有入口单独删除。
5. 清理本机会话并尽力请求专用 `/auth/logout`，分别报告本机凭据和服务端请求失败。内存会话始终丢弃；不请求旧 API，不管理模型 Key。
6. 前端清空查询缓存，阻止轮询/旧同步恢复身份。完整结果保存在 Auth Context，退出门禁后通过独立可关闭弹窗查看逐应用保留项和各步骤状态，不占用登录表单。关闭即清除内存结果。IPC 在验证前失败时进入恢复重试页，不谎报已退出。

普通退出维持现有容错语义。显式清理会报告 keyring 删除失败，即使会话指针已经失效；两者不能混为「所有凭据已删除」。这是范围受限的逻辑删除，不是磁盘安全擦除；配置修改记录、备份、自建项和安全保留项仍可能包含凭据。凭据引用损坏或系统凭据库持续不可用时，可能需人工处理残留条目。

## 验证与回退

回归覆盖同平台不同用户、同用户 ID 不同平台、旧 v2 迁移、写入失败保护、损坏快照、其他账号字节不变、身份过时拒绝、部分清理仍退出、keyring/服务端双重失败、确认取消、普通退出、账号切换关闭详情及迟到响应。实际执行结果以 [VALIDATION](../history/validation.md) 为准。

代码可回退本次自有模块、入口注册和翻译差异。旧二进制不会读取新的账号目录，因此降级后需重新登录并同步当前账号；不自动把其他账号快照回填单文件，也不恢复已删除的会话凭据。已清理的数据可通过重新登录和平台同步重建，供应商原生配置恢复仍使用已有历史/备份入口，不能全量回滚整个工具目录。真实系统 keyring、实际 CLI 运行和 Windows/Linux 权限语义须另行验收。

## 交互与范围修订

根据用户反馈，清理范围限定为账号的平台基础数据、平台托管供应商和本次登录会话，保留登录历史、平台地址和已记住密码。清理结果采用可关闭弹窗。工具同步的兼容性警告及错误继续使用浮动提示和既有配置修改记录，不污染平台目录的错误状态。

弹窗视觉修订：确认框与结果框使用一致的 440px 最大宽度及正文留白；标题、操作区固定，仅正文滚动。结果先展示数量和步骤状态，逐应用明细默认折叠；确认框保留登录信息说明常显，其他保留范围折叠查看。复用现有 Dialog、主题色与供应商结果组件，后者默认展开的既有调用不变，仅清理结果传入默认折叠参数。
