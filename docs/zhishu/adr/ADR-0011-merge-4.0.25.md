## 场景、验收与方案

吸收 4.0.24–4.0.25 的上游功能及修复，保留智枢 0.0.6 身份、OAuth2 会话、两阶段平台同步、WorkBuddy、配置历史和 ADR-0009 共存隔离。验收要求保留双方提交祖先关系、解决全部冲突、完成前后端静态检查和隔离回归，且不触碰真实用户配置。

候选方案：整文件采用上游会丢失智枢身份和归属保护；仅挑选提交会遗漏版本内依赖关系且失去完整祖先关系；选择从当前产品 HEAD 建立 `sync/upstream-4.0.25`，三方 merge 后逐块适配。核心内部调用和穷举分派无法通过纯新增 Adapter 代替，沿用既有服务，不复制核心。

拟修改上游文件覆盖依赖清单、Tauri 固定入口（L1）、现有 UI/翻译和 IPC wrapper（L1/L2），以及代理、配置投影、Provider/MCP/用量/设置服务及测试（L3）。准确清单以同步提交相对第一父提交的 diff 为准。新增本 ADR 和同步报告，更新基线、补丁台账及文档索引（L0）。锁文件由依赖工具生成，不手工拼接。

## 数据、安全及跨平台边界

上游本次未提升 schema 24，新增定价和设备设置沿用现有存储；Pi 用量解析版本变化会重新导入历史。保留 v23 OMP 幂等协调。平台凭据协议、Key 生命周期、身份、更新地址及产品版本不变。本次不合并 `origin/ccs-dev` 的既存分歧、不推送、不发布、不迁移真实数据。

保留智枢专有代理占位符、Stack ID、Desktop profile、写入归属、首写备份和 pending 恢复。吸收上游浏览器请求防护，Claude 路由占位符改写 AUTH_TOKEN 时使用智枢值。保留上游文件和兼容入口；上游删除项须单独按仓库保留规则复核。

上游新增 rmcp 0.8.5（MIT）、process-wrap 8.2（锁定 8.2.2，Apache-2.0 OR MIT），用于复用 MCP 握手和进程树清理；Windows 新增 webview2-com/windows 直接依赖，用于关闭 WebView 自动填充。许可证已以下载的 crate 清单复核。前端升级 smol-toml 1.9.1。macOS 本机验证不能替代 Windows/Linux 编译及进程清理、真实系统 keyring 或 CLI 请求验收。
