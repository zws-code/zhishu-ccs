# ADR-0009：与原版 CC Switch 的资源归属隔离

- 日期：2026-11-03；状态：按用户“修复这些问题”授权实施，验证结果另记，不代表发布批准。
- 等级：L0 自有 identity/coexistence 模块；L1 品牌入口；L3 配置投影、后台恢复、Skills 和同步边界。

## 场景与验收

用户同时安装智枢与原版，共同管理 Codex 等工具。智枢自有派生文件、路由、聚合模型、Desktop profile、DSH 回执和云同步空间不得与原版同名；启动/退出不能凭通用占位符认领另一款应用的配置。主动切换是用户的配置交接，继续复用既有 ProviderService、原子发布、首写备份与 pending 恢复。平台本地同步仍无联网、覆盖确认或整目录备份。

## 选择与边界

产品名称集中在 `zhishu/identity.rs`；持久化的后台写入归属检查位于自有 coexistence 模块，上游仅在写入完成及启动/退出处接入。无法只通过外层包装解决：现有路径、投影和后台恢复在内部直接引用常量并发布文件，Skills 也直接修改原生目录。保留全部上游函数和兼容入口。

智枢使用 `zhishu-ccs-model-catalog.json`、独立 Codex 路由与聚合前缀、Desktop profile 和 DSH 回执。旧原版同名文件、表、profile、脚本与远端对象不自动删除、认领或迁移。旧聚合模型标识无法可靠区分来源，不把原版 ID 自动映射到智枢供应商；旧会话可保留，需重新选择智枢模型。Codex 历史迁移使用的旧桶标识保留，不以这次命名隔离为理由批量改写共享会话数据库。既有明确选择的官方历史统一迁移按 live 实际路由选择目标桶；还原器同时支持新旧桶且仍只改备份账本中记录的会话 ID，降级前先用本版还原新桶迁移。

已有云同步设置原样保留：上游默认根拒绝同步并明确提示选择独立目录，不静默改路径；新配置默认 `zhishu-ccs-sync`，新 manifest 使用独立格式，上传前检查目标归属，下载拒绝原版/未知快照。旧智枢快照因与原版无法可靠区分，也不自动接管；可保留备份，通过原有本地导入恢复后上传到独立目录。

共享原生配置不可能同时具有两个当前供应商。后台仅在可验证的智枢归属下恢复/分离，外部改写保留，主动切换继续明确交接。通用 hash 检查不是与原版的跨进程事务锁；不宣称阻止原版在智枢之后主动覆盖配置。Skills 不覆盖/删除指向其他来源的同名链接或内容不同的未知目录；Unified 存储是用户显式共享选项。

共存审查收敛：Codex 当前 profile 仅将 `model_provider`、`openai_base_url`、`experimental_bearer_token` 纳入归属指纹，与既有有效路由校验保持同一字段范围；模型、推理档位等普通偏好不阻止分离和重连，发布前并发检查继续保留。`comp_hash` 是会话压缩协议分组值，沿用 `cc-switch` / `cc-switch-<tool_mode>`，不随产品品牌改名。AGY 可执行程序发现同时排除两款产品的旧包装脚本，自动清理仅接受智枢标记；识别外来脚本不等于获得删除权限。

Codex 浏览器授权固定回调端口受 OAuth 客户端约定限制，保留协议、占用错误及设备码入口，不抢占监听器、不静默改变登录方式。平台 OAuth 继续用随机端口。

## 备选方案

- 全局替换 cc-switch 字样：无法解决共享原生配置，还会破坏历史、授权协议和第三方资源，否决。
- 全量复制各 CLI home：会造成会话、凭据、插件分裂，超出用户场景与 L3 范围，否决。
- 仅改模型目录名：不能处理后台误接管和云同步串库，否决。

## 风险、验证与回退

验证包括隔离 home 下外部代理保留、后台归属失效、正常启停、未知字段与 profile 保留、同步快照拒绝、Skills 外来链接保护、旧文件保留及现有故障/pending 回归；前端类型、相关测试、Rust 格式及测试按实际结果记入验证记录。真实双应用、各 CLI、系统凭据库及跨平台安装验收需单独记录。

回退代码不删除新旧派生文件、不移动远端对象、不重写会话历史；使用原有配置历史/首写备份按文件恢复，恢复前保留当前内容。新同步协议需保持独立目录；降级前停用新同步，不能把新快照投到原版根目录。旧聚合模型需重选旧版名称，Desktop 可切回保留的旧 profile。

本 ADR 明确修订 AGENTS 中“第三方固定 custom 表”的当前实现描述：新投影改用产品独立表，但保留上游输入解析和旧表内容；不把解析兼容当成所有权证据。复审日期：2026-11-03，按本次验证更新。
