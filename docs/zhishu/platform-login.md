# 智枢router 平台登录（第一版）

主窗口启动后先显示登录页，登录成功后进入原有应用界面。侧栏显示平台账户并提供退出入口；不再区分新手模式与高级模式。

## 开发运行

1. 启动 zhishu-proxy 后端 `http://127.0.0.1:3000` 与网页前端 `http://127.0.0.1:3081`。
2. 在 cc switch 中运行 `pnpm install`，再运行 `pnpm dev`。客户端自己的 Vite 服务使用 1420 端口。
3. 使用现有平台账户邮箱和密码登录。启用 TOTP 的账户还需要输入六位验证码。

默认地址已匹配上述开发环境。可复制 `src/.env.example` 为 `src/.env.local` 修改构建配置，正式环境将两个地址都配置为同一 HTTPS 站点，重新构建即可。登录页也允许输入后端地址；注册和找回密码链接使用构建时配置的网页地址。

## 接口与会话

直接复用平台 `/api/v1/settings/public`、`/auth/login`、`/auth/login/2fa`、`/auth/me`、`/auth/refresh`、`/auth/logout`，不修改平台后端。Rust 发起 HTTP 请求，避免 WebView 跨域问题；拒绝重定向与远程明文 HTTP。本机 localhost、127.0.0.1、IPv6 回环允许 HTTP。

访问令牌与二次验证临时令牌仅保存在 Rust 进程内存中；刷新令牌默认保存在系统凭据库的独立 service `com.zhishu.ccswitch.desktop.platform-session`，不发送给前端，不写入 localStorage、数据库、配置导出或同步文件。设备本地 `platform-session.json` 只保存平台地址、用户 ID、凭据条目 ID 和最后使用时间，以原子方式写入，Unix 权限为 0600；它与登录历史使用相同的应用本地数据目录，开发隔离环境使用隔离目录，凭据条目也按目录区分。完全退出客户端、重启应用或电脑后，客户端读取刷新令牌并向平台验证，成功后直接进入主界面。连续超过 7 天未使用则清除本机会话并要求重新登录；这是客户端的不活跃期限，不是每隔 7 天强制登录。窗口可见且未最小化时更新最后使用时间，隐藏到托盘、最小化和后台轮询不续期。服务端仍可提前撤销凭据，实际登录恢复以服务端校验为准。登录成功后在本机应用数据目录记录平台地址与邮箱，按最近登录排序；可在登录页切换账号或删除记录。默认不保存密码；勾选“记住密码”后，密码仅存入系统凭据库（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），不写入 localStorage、配置数据库、导出或云同步。重新打开登录页时自动填入最近账号及已保存的密码，仍需点击登录，启用 TOTP 的账号仍需二次验证。取消勾选会立即删除该账号的已保存密码，删除记录也会删除对应密码。系统凭据库不可用时仍保存账号记录并显示提示，登录成功不受影响；无法保存刷新令牌时，本次可使用，但不能跨重启保持登录。保持登录不依赖“记住密码”，不会使用已保存密码自动重新登录或跳过二次验证。

客户端每分钟以及窗口重新可见、网络恢复时查询账户状态。401 时使用刷新令牌轮换后重试；轮换结果在后续请求之前写回系统凭据库，即使随后账户查询失败也保留新凭据，凭据库暂不可用时保留内存中的轮换结果并允许重试保存。凭证失效或账户被禁用时清除本机会话并返回登录页，同时清除前端账户缓存。暂时断网时保留会话并提示错误；启动恢复失败时显示重试页面，不会直接清除凭据或开放未验证的离线入口，也可以主动返回登录页。退出先失效本地会话指针、删除系统凭据库条目，再尝试撤销平台刷新令牌；即使凭据库删除暂时失败，失效指针也阻止下次自动恢复。撤销失败会提示，原有平台托管工具凭证清理流程继续执行。

## 当前范围和限制

- 支持邮箱密码和 TOTP，注册、找回密码跳转现有平台网页。
- 平台开启 Turnstile、腾讯或阿里云人机验证时，当前版本提示暂不支持并阻止邮箱登录。需要后续实现浏览器授权与一次性交换码，保留原有人机验证；不要通过关闭验证绕过。
- 暂不包含第三方 OAuth、扫码。登录成功后自动同步当前账户可用分组，并按 `zhishu-ccs-<分组平台>-<分组 ID>` 查找或创建分组专用 Key；Key 不进入前端或云同步。退出登录仅清除会话，保留本机托管配置里的 API Key；需要清理供应商时使用显式删除入口，详见[账号服务供应商同步与分组专用 Key](platform-managed-models.md)。
- 登录页是主窗口的产品入口，不是本地配置的安全隔离机制。现有托盘与原有本地工具管理逻辑保持原样，平台接口仍必须由后端校验会话权限。后续平台专属操作必须在 Rust 端验证登录状态。

左下角账户区域显示平台美元余额，侧栏收起时仍显示金额。余额每分钟及窗口重新可见时随账户信息刷新，也可点击余额行手动刷新。小于 0.01 美元的非零余额显示六位小数，其余显示两位。
