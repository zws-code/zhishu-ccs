# 与原版 CC Switch 共存

实施依据：[ADR-0009](../adr/ADR-0009-product-coexistence.md)。源码改动不自动安装到已有客户端；验证范围见[验证记录](../history/validation.md)。

## 智枢独立资源

| 资源 | 智枢名称 |
| --- | --- |
| Codex 派生目录 | `zhishu-ccs-model-catalog.json` |
| Codex live 路由表 | `[model_providers.zhishu]` |
| 代理占位符 | `ZHISHU_CCS_PROXY_MANAGED` |
| Codex 聚合模型 | `zccs-<key>/<model>` |
| Claude 聚合模型 | `zccs-claude-<key>--<model>` |
| Desktop 聚合模型 | `claude-fable-zccs-<6位数字>` |
| Desktop profile | `00000000-0000-4000-8000-000000257210` / `Zhishu CC Switch` |
| DSH profile 初始化回执 | `.zhishu-ccs-profile-sync.json` |
| DSH 新 MCP 插件 ID | `zhishu-ccs-mcp-<id>` |
| 新云同步默认根、manifest 格式 | `zhishu-ccs-sync` |

应用身份、应用数据目录、平台 keyring service 和默认代理端口仍保持既有智枢值，不迁移登录凭据或安装身份。

## 升级与共享原生配置

- 原版同名派生文件、`custom` / `cc-switch-official` 表、旧 Desktop profile、旧 DSH 回执和 agy 脚本保留；不因为文件名或通用占位符相同就认作智枢资产。
- 用户主动选择供应商或接入路由是交接操作，仍走现有原子写入、首写备份和 pending 恢复。配置中的无关字段继续按各适配器规则保留。
- 智枢在成功写入后保存设备本地的路径/哈希归属记录，文件为 `zhishu-live-owner-<摘要>.json`，0600，不包含 Key、token 或配置正文。CLI 配置路径改变后，只对新路径重新建立归属。
- 启动、退出先检查归属；未知、损坏或外部接管的配置保留，保存的代理模式不等于原生文件所有权。旧版没有归属记录时，需要用户主动接入；有产品独立路由/标记且端点匹配的代理可以识别。后台 attach/detach 在发布前发现并发写入时停止，不以新内容为底强行重算覆盖。
- 原版以后主动切换仍可能改动同一套 CLI 配置；本修复没有修改原版，也不宣称为两款应用提供共同遵守的跨进程事务锁。同一原生配置只能有一个当前生效的供应商。
- 旧 `ccs-*` 聚合 ID 不通过智枢登记簿反查，避免把原版模型映射到同名但不同的供应商。旧会话文件不改写，使用时需重新选择新的智枢模型；跨版本真实续聊待验收。
- 默认共享 Codex home 不再在智枢启动时自动归并历史桶；现有迁移/还原函数保留。配置目录明确放在智枢私有数据根下时，仍可执行既有自动迁移。历史桶 `custom` 与新的 live 路由 ID 是不同用途，不做全局替换。用户明确选择“迁入既有官方会话”时，迁移目标随实际 live 的 `custom` 或 `zhishu` 路由选择，原有备份账本限定还原的会话 ID，新旧两代均可还原，其他会话保持不变。降级前应先用本版还原入口处理新桶的迁移；旧版还原器不认识 `zhishu` 桶。

## 云同步

新配置使用独立默认根。已有 root/profile/凭据原样保留，旧配置缺失 root 时仍解释为旧默认 `cc-switch-sync`；该空间拒绝读写并提示用户主动选择独立目录，不静默切换远端路径。

上传在写数据库/Skills 对象之前检查远端 manifest。原版、未知或不兼容的 manifest 拒绝；没有 manifest 但存在未知产物也拒绝。全新空空间先保存独立 `zhishu-owner.json` 标记，再维持原有“产物先、manifest 后”的发布顺序。存在有效智枢标记的部分上传可重试。下载不导入原版或无法确认来源的旧快照。

旧智枢远端快照的协议与原版相同，不能仅凭格式自动认领；保留原对象，先备份，通过既有显式本地导入流程恢复后再上传到独立目录。新格式不被旧版客户端接受；降级前停用新同步，不把新快照写进原版默认根。

## Skills、MCP 和登录

同名 Skill 仅在链接确实指向本机智枢主副本，或副本内容/本机部署记录可验证时更新和删除。内容不同、指向其他来源的目录/链接保留并报告；部署副本的记录仅包含路径和内容哈希。Unified 的 `~/.agents/skills` 仍是用户明确选择的共享存储。

DSH 遇到带 `cc-switch-mcp-*` 的原版节点拒绝覆盖/删除，提示使用不同服务器名称。其他无来源标识的原生 MCP 节点仍属于用户共同管理的工具配置，主动编辑会影响实际使用该配置的工具。

Codex 浏览器登录继续使用授权协议规定的 `1455` 端口；被其他应用占用时明确提示选择设备码或先完成另一处登录，不关闭别人的监听器、不静默切换认证流程。回调响应关闭连接，避免新登录复用旧流程的连接。智枢平台 OAuth 独立使用随机回环端口。
